# Внешние файлы

Сюда кладутся два необязательных хелпера. Без них виджет работает,
но без транспорта плеера на Windows и без громкости по приложениям.

| Файл | Зачем | Откуда |
|---|---|---|
| `smtc.exe` | название, артист, обложка, play/pause/next/prev на Windows | собрать из `smtc-helper/` командой `dotnet publish -c Release` |
| `svcl.exe` | громкость каждого приложения на Windows (WASAPI) | NirSoft SoundVolumeView, консольная версия |
| `tray.png` | иконка в трее, 32 × 32 | своя |

На Linux ничего класть не нужно: `playerctl` и `pactl` уже есть в системе.
