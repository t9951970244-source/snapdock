SNAPDOCK

Просто посмотреть дизайн:
  открыть preview.html двойным щелчком

Запустить на Mac:
  1. Открыть Терминал (Cmd + пробел, набрать "Терминал")
  2. Вставить одну строку и нажать Enter:

     cd ~/Downloads/snapdock-final && npm install && npm run build && npx electron .

  3. Ждать 4-6 минут. Виджет появится в правом нижнем углу.
     Терминал не закрывать, можно свернуть.

Управление:
  полоска слева   - перетащить виджет
  колесо мыши     - громкость
  Ctrl+Shift+1    - снять область экрана
  Ctrl+Shift+2    - снять весь экран
  Ctrl+Shift+D    - спрятать и показать
