# Свой ретранслятор на Beget — чтобы связь не рвалась

## Зачем

Сейчас два компьютера пытаются достучаться друг до друга напрямую. Для этого
хотя бы один должен принимать входящие соединения, а брандмауэр Windows и роутер
их закрывают. Связь встаёт на первых секундах и умирает, когда начинается
проверка пути.

Ретранслятор решает это целиком. Оба компьютера подключаются к нему
**исходящим** соединением, каждый со своей стороны через своего провайдера.
Входящие порты не нужны вообще. Если прямой путь есть — трафик идёт напрямую и
ретранслятор простаивает. Если прямого пути нет или он оборвался — разговор
продолжается через ретранслятор и не прерывается.

Читать содержимое ретранслятор не может: шифрование сквозное, плюс наш пароль
поверх. Он перекладывает зашифрованные байты.

---

## Что нужно на Beget

**Обычный хостинг не подойдёт** — нужны свои порты и права администратора.
Нужен **VPS** (у Beget это раздел «VPS» или «Облачные серверы»). Самый дешёвый
тариф справится: ретранслятор почти не ест процессор, ему нужен только канал.

Ориентир: 300–600 ₽ в месяц. Трафик — примерно 1 ГБ на час разговора вдвоём, и
только когда прямой путь не сложился.

При заказе выберите **Ubuntu 24.04**. Запишите адрес сервера и пароль root.

---

## Шаг 1. Зайти на сервер

На Mac откройте Терминал и выполните, подставив свой адрес:

```
ssh root@АДРЕС-СЕРВЕРА
```

Введите пароль. Дальше все команды выполняются там.

## Шаг 2. Поставить ретранслятор

```
apt update && apt install -y coturn
```

## Шаг 3. Настроить

Создайте настройку одной командой. **Замените** `АДРЕС-СЕРВЕРА` на адрес вашего
VPS, а `ПРИДУМАЙТЕ-ПАРОЛЬ` — на любой длинный пароль без пробелов.

```
cat > /etc/turnserver.conf << 'EOF'
listening-port=3478
tls-listening-port=5349
fingerprint
lt-cred-mech
user=snapdock:ПРИДУМАЙТЕ-ПАРОЛЬ
realm=snapdock
external-ip=АДРЕС-СЕРВЕРА
min-port=49160
max-port=49200
no-multicast-peers
no-cli
EOF
```

Включите автозапуск:

```
sed -i 's/^#TURNSERVER_ENABLED/TURNSERVER_ENABLED/' /etc/default/coturn
systemctl enable coturn && systemctl restart coturn
```

## Шаг 4. Открыть порты

```
ufw allow 3478/tcp && ufw allow 3478/udp && ufw allow 5349/tcp && ufw allow 5349/udp && ufw allow 49160:49200/udp
```

Если в панели Beget есть свой брандмауэр — откройте те же порты и там.

## Шаг 5. Проверить

```
systemctl status coturn
```

Должно быть написано `active (running)`.

## Шаг 6. Вписать в приложение

На обоих компьютерах: откройте виджет → **Чат** → вкладка **В одной сети** →
ссылка **Свои серверы связи**. В верхнее поле впишите одну строку:

```
turn:АДРЕС-СЕРВЕРА:3478?user=snapdock&pass=ПРИДУМАЙТЕ-ПАРОЛЬ
```

Нажмите **Сохранить** и перезапустите приложение. На обоих компьютерах одно и
то же — иначе они не договорятся.

---

## Если нужно ещё и через интернет, а не только в одной сети

Тогда на том же сервере поднимите сервер знакомства — он заменит общий
бесплатный, который постоянно не отвечает.

```
apt install -y nodejs npm
npm install -g peer
```

Запуск как служба:

```
cat > /etc/systemd/system/peerjs.service << 'EOF'
[Unit]
Description=PeerJS
After=network.target

[Service]
ExecStart=/usr/bin/peerjs --port 9000 --key peerjs --path /
Restart=always

[Install]
WantedBy=multi-user.target
EOF
systemctl enable peerjs && systemctl start peerjs && ufw allow 9000/tcp
```

В приложении в нижнее поле настроек впишите:

```
http://АДРЕС-СЕРВЕРА:9000
```

После этого заработает вкладка **По коду комнаты** — уже между любыми
компьютерами в интернете, а не только в одной квартире.

---

## Порядок проверки

1. Сначала только ретранслятор, вкладка **В одной сети**. Связь не должна рваться.
2. Если всё ровно — добавьте сервер знакомства и проверьте **По коду комнаты**
   с компьютера в другом месте.

Если что-то не поднялось, пришлите вывод команды `systemctl status coturn`.
