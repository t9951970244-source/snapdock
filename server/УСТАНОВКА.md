# Комната на своём сервере — просто и надёжно

## Что получится

Одна веб-страница, которая открывается **на чём угодно**: Mac, Windows, айфон,
андроид, планшет. Никакой установки. Зашли по ссылке, ввели название комнаты и
имя — вы вместе. Видео, переписка, файлы любого размера.

Связь держит сервер, поэтому она не рвётся. Обрыв интернета — страница
подключается заново сама, ничего вводить не нужно.

## Почему это проще того, что было

Раньше два компьютера искали друг друга напрямую. Это бесплатно, но ненадёжно:
мешают брандмауэр, роутер, провайдер. Теперь есть посредник, который всегда на
месте — и всё становится предсказуемым.

## Установка: восемь команд

Нужен **VPS** на Beget (раздел «VPS» или «Облачные серверы»), самый дешёвый
тариф, **Ubuntu 24.04**. Ориентир 300–600 ₽ в месяц.

**1. Зайти на сервер.** В Терминале на Mac:

```
ssh root@АДРЕС-СЕРВЕРА
```

**2. Поставить Node.js:**

```
apt update && apt install -y nodejs npm
```

**3. Положить файлы.** Папку `server` из архива загрузите на сервер в
`/opt/snapdock`. Проще всего — прямо с Mac, отдельным окном Терминала:

```
scp -r ~/Downloads/snapdock-final/server root@АДРЕС-СЕРВЕРА:/opt/snapdock
```

**4. Установить зависимость:**

```
cd /opt/snapdock && npm install
```

**5. Сделать службу**, чтобы сервер поднимался сам после перезагрузки:

```
cat > /etc/systemd/system/snapdock.service << 'EOF'
[Unit]
Description=SnapDock room server
After=network.target

[Service]
WorkingDirectory=/opt/snapdock
ExecStart=/usr/bin/node server.js
Environment=PORT=8080
Restart=always

[Install]
WantedBy=multi-user.target
EOF
systemctl enable snapdock && systemctl start snapdock
```

**6. Открыть порт:**

```
ufw allow 8080/tcp
```

**7. Проверить:**

```
systemctl status snapdock
```

Должно быть `active (running)`.

**8. Открыть в браузере:**

```
http://АДРЕС-СЕРВЕРА:8080
```

Готово. Эту ссылку можно отправлять кому угодно.

## Сделать по-человечески: адрес и замок

Браузеры на телефоне **не дадут доступ к камере без замка** — нужен `https`.
Поэтому если планируете звонить с телефона, этот шаг обязателен.

Заведите поддомен, например `chat.ваш-домен.ру`, и направьте его на адрес VPS.
Потом:

```
apt install -y nginx certbot python3-certbot-nginx
cat > /etc/nginx/sites-available/snapdock << 'EOF'
server {
  server_name chat.ваш-домен.ру;
  location / {
    proxy_pass http://127.0.0.1:8080;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    client_max_body_size 0;
  }
}
EOF
ln -sf /etc/nginx/sites-available/snapdock /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx
certbot --nginx -d chat.ваш-домен.ру
```

После этого адрес будет `https://chat.ваш-домен.ру` и камера заработает везде.

## Если видео не проходит через строгую сеть

Один раз добавьте ретранслятор — тогда видео пойдёт гарантированно, даже через
корпоративный интернет и мобильную сеть:

```
apt install -y coturn
cat > /etc/turnserver.conf << 'EOF'
listening-port=3478
fingerprint
lt-cred-mech
user=snapdock:ПРИДУМАЙТЕ-ПАРОЛЬ
realm=snapdock
external-ip=АДРЕС-СЕРВЕРА
min-port=49160
max-port=49200
no-cli
EOF
sed -i 's/^#TURNSERVER_ENABLED/TURNSERVER_ENABLED/' /etc/default/coturn
systemctl enable coturn && systemctl restart coturn
ufw allow 3478 && ufw allow 49160:49200/udp
```

Скажите серверу комнат, где ретранслятор:

```
sed -i 's|Environment=PORT=8080|Environment=PORT=8080\nEnvironment=TURN=turn:АДРЕС-СЕРВЕРА:3478?user=snapdock\&pass=ПРИДУМАЙТЕ-ПАРОЛЬ|' /etc/systemd/system/snapdock.service
systemctl daemon-reload && systemctl restart snapdock
```

Страница подхватит его сама — участникам ничего вводить не нужно.

---

## Обновление

Заменили файлы — перезапустите:

```
systemctl restart snapdock
```

## Что сервер хранит

Ничего. Сообщения и файлы проходят насквозь и нигде не записываются. Вышли все
из комнаты — комната исчезла.
